# Ecourts Causelist Downloader

This project is designed to download causelists from the Ecourts website for various districts and courts in India.

## Features

- Scrape and download causelists for different courts and districts.
- Generate PDFs from the downloaded data.
- Real-time causelist scraper functionality.

## Usage

Run the main application:

```bash
python realtime-app.py
```

## Structure

- `scraper/`: Contains scraping scripts.
- `templates/`: HTML templates for the web interface.
- `downloads/`: Directory for downloaded files.
- `logs/`: Log files.
